# 🎮 P2P Tic Tac Toe — C#
<img width="1806" height="760" alt="image" src="https://github.com/user-attachments/assets/b47f815c-01c5-4653-8ca9-e700871d224b" />

A desktop-based **Peer-to-Peer (P2P) Tic Tac Toe game** developed in C# that allows players to discover other computers on the local network and invite them to play.

The application features a modern dark-themed graphical user interface, player discovery, and a classic 3×3 Tic Tac Toe board.

## 📸 Project Preview

The application interface includes:
- A **Discovered Players** panel to display available computers.
- A **Refresh** button to scan for available desktops.
- An **Invite** button to invite another player.
- A **3×3 Tic Tac Toe game board**.
- Player information displayed at the bottom of the window.

## ✨ Features

- **Peer-to-Peer Gaming:** Designed for multiplayer gameplay between computers.
- **Player Discovery:** Displays discovered computers on the local network.
- **Player Invitations:** Allows users to invite available players.
- **Interactive Game Board:** A traditional 3×3 Tic Tac Toe interface.
- **Modern UI:** Dark theme with cyan highlights and a clean desktop layout.
- **Local Network Support:** Designed for use on a local network.
- **Refresh Functionality:** Refresh the player list to discover available desktops.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project

Open the project in **Visual Studio** and load the C# solution or project file (`.sln` or `.csproj`).

### 3. Build and Run

If the project uses the .NET CLI, open a terminal in the directory containing the `.csproj` file and run:

```bash
dotnet restore
dotnet build
dotnet run
```

Alternatively, open the solution in Visual Studio, build the project, and run it.

## 🎯 How to Use

1. Launch the application on both computers.
2. Connect both computers to the same local network if required.
3. Wait for the application to discover available players.
4. Click **Refresh** if another player does not appear.
5. Click **Invite** beside the desired player.
6. Start playing when the multiplayer session is established.

*Note: The exact connection and gameplay steps depend on the networking and game logic implemented in the project.*
